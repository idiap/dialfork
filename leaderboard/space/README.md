# DialFork Leaderboard

The leaderboard of [DialFork](https://github.com/idiap/dialfork) ([paper](https://arxiv.org/abs/2610.21561)), a benchmark for procedural hallucination in conversational agents.

This Space is a single static page. It reads the rows from [`leaderboard/v1.json`](https://github.com/idiap/dialfork/blob/main/leaderboard/v1.json) on GitHub, so a merged pull request shows up here with no redeploy. To add your method, see [how to add your method](https://github.com/idiap/dialfork/blob/main/docs/leaderboard.md#how-to-add-your-method).
